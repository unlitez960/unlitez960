# Hi, I'm unlitez960! 👋

Pandas and SQL are my daily companions, though lately I've been reaching for DuckDB more than I expected — it's changed how I think about local analytics. I'm drawn to the plumbing side of data work: the pipelines, the transformations, the part where you figure out why row counts don't match at 11pm.
